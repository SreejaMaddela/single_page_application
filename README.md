# Task 3: Single-Page Application (SPA) with Data Fetching

## Description
A minimal React SPA that fetches and displays user data from an API. Users can click on a name to view detailed information interactively.

## Features
- Built with React and Vite
- Fetches dynamic data from JSONPlaceholder API
- Click-to-view user details
- Simple, interactive UI

## How to Run
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Open the URL shown in the terminal (usually `http://localhost:5173/`).
